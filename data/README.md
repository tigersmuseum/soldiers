## Reference data

This folder is for reference data that should be standard across all soldiers database instances:

* [ranks.csv](rank.csv) is instance data for the [RANK](https://github.com/tigersmuseum/soldiers/blob/main/schema/derby/soldiers.sql) table.
The columns are: rank abbreviation, rank title, [NATO rank code](https://en.wikipedia.org/wiki/NATO_military_rank_codes) (not currently used), and an ordinal number 
that can be used to sort ranks by seniority.
